# Worship Hub

Застосунок для групи прославлення: усі пісні в одному місці, з акордами й без,
у тональності кожного музиканта.

## Що вміє

- **Один текст — три режими.** Пісня зберігається у ChordPro (`[G]Слава [D]Тобі`),
  а показується як «тільки текст» (вокал), «акорди над словами» (гітари, клавіші)
  або «сітка акордів» (бас, барабани).
- **Транспонування на льоту.** Кожен бачить свою тональність; каподастр перераховує аплікатуру.
- **Секції як блоки.** Вступ / Куплет / Приспів / Міст / Програш — тягнеш і міняєш порядок.
- **Сет-листи** на дату: порядок пісень, тональність для всієї групи, хто веде.
- **Персональні нотатки** на пісню — бачить тільки власник; спільні — усі.
- **Автоскрол**, темна тема, екран не гасне під час гри.
- **PWA**: ставиться на домашній екран, працює офлайн.

## Розробка

```bash
npm install
npm run dev
```

## Деплой на GitHub Pages

```bash
npm run deploy
```

## Архітектура

Дані проходять через `src/storage/adapter.ts`. Зараз підключено `local.ts`
(localStorage, дані на пристрої). Для спільної бази на всю групу достатньо
додати Supabase-адаптер з тим самим інтерфейсом і підмінити його в
`src/storage/index.ts` — решта застосунку не змінюється.
